Quand il apparaît. Seulement si la page met plus de 0,3 seconde à venir. Avec une bonne connexion, l’usager ne le voit presque jamais.

Animations réduites. Si le téléphone est réglé pour réduire les animations, le logo s’affiche fixe, sans mouvement.

Poids. Le logo est dessiné par le code du site (environ 5 Ko) : pas de vidéo, pas de son, affichage immédiat même en 3G.
